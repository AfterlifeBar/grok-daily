01Meta 发布 Muse Wonder：主打个人与职业 Agent，1M 上下文，标配 Active Memory / Active Focus

10 月 12 日 Meta 推出 Muse Wonder 与 Muse Wonder Full：面向个人与职业智能体任务，推理上下文长度 1M tokens，输入支持文本、图像、视频、音频与 PDF。官方称二者在 personal/professional agent、记忆与编程相关基准上达到当前最佳，并强调 Active Memory（跨对话携带并取回关键上下文）与 Active Focus（遇阻后换路径、必要时先确认再行动）。Muse Wonder 已通过 Meta Model API 与 Muse Code 开放；Full 版仅限 Muse Code 订阅用户。模型卡写明在化学与生物领域未缓解前不排除达高风险阈值，部署依赖安全后训练与系统级分类器。

02Anthropic：新反蒸馏体系使被抽取的推理 token 降至原先的 1/10–1/100，收获数据约降 90%–99%

10 月 12 日 Anthropic 披露近几个月的反蒸馏进展：蒸馏攻击用欺诈账号网络批量抽取 Claude 推理轨迹，以低成本复制前沿能力。新方法包括 preserved thinking（限制新账号改写先验上下文）、两阶段分类器（误报率 <0.1%），以及对反复提取的限流与封禁；自 9 月 24 日起在低误报领域对被拦截请求重新计费。公司称平台上可被蒸馏者抽走的推理 token 已下降 10–100 倍。文中点名智谱 GLM-5.3 蒸馏美国模型网络能力，以及 Moonshot 请求被秘密转发至 Claude 的案例，并呼吁其他开发者与云平台共同打击。

深度阅读

Anthropic：反蒸馏不是公关稿，是一套可复用的防御框架与代价账单

核心论点：非法蒸馏会把前沿能力带到安全护栏不成比例的模型上，并进入外国军情体系，因此必须用与防生物/网络滥用同级的工程手段去打。关键证据：summarize reasoning 就把 SWE-bench Verified 蒸馏得分从 80.4% 打到 71.8%；新分类器上线后平台可抽取推理 token 降 10–100 倍、收获数据约降 90%–99%；误报 <0.1%，并对被拦请求重新计费。增量在于把“preserved thinking + 两阶段分类器 + 账号级封禁计费”写成可迁移的行业打法，并点名智谱/Moonshot 案例。边界：效果是否持久仍未知；措施已迫使部分合法开发者改集成；若其他实验室与云平台不同步，单点防御会被绕开。

哈玛克《Trimming the Sails》：把反应函数讲清楚，并把 AI 需求写进通胀因果链

核心论点：联储必须解释“看到什么、如何反应”，但反应函数不是对利率路径的承诺；在当前条件下需要限制性立场，以便及时回到 2%。关键机制：她把通胀拆成关税连击（供给）与 AI 基建零部件需求（需求）两条非自我纠正的路径，再用地区调研中的“加价超过当前成本”作为通胀预期固化的微信号。增量：把 AI capex 从增长故事改写成货币政策输入变量，并明确偏好“小步快跑”纠偏。边界：未给出 10 月会议的明确加息投票；中性利率与金融条件判断高度主观；地区轶事不能替代全国数据。
