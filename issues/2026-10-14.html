01Anthropic 自研版本控制 Scion：日合并从约 2500 飙到超 3 万，五个月迁完 monorepo

10 月 13 日 Anthropic 工程博客披露：2026 年 5 月 monorepo 日均合并约 2500 次，9 月已超 3 万次；主分支历史近 100 GB、压缩工作副本逾 25 GB，CI 每日约 2500 万次 checkout，若按 git 全量拉取可达约 600 PB/日流量。公司判断 git 为人类离线协作设计的属性，已成 Agent 规模瓶颈，于是自建集中式系统 Scion（changeset 写前日志、服务端提交/合并、稀疏/虚拟化 checkout），并同周期上线代码评审 Antique；七人团队五个月完成迁移。基础设施 footprint 称较原 git 镜像方案缩约 200 倍，CI 单 checkout 从分钟级到秒级。公司明确 Scion 不适合通用替代 git、暂无开源计划，但预期同类压力会在 6–12 个月内扩散到其他重度 Agent 组织。

深度阅读

Bain《Technology Report 2026》：AI 要养活自己的基建，缺口不在算力，在新市场

核心论点：到 2031 年，支撑约 1.5 万亿美元年 AI 基建开支（按 capex≈收入 25% 的云厂商经验）需要接近 6 万亿美元的年行业收入；现有消费+企业应用合计仅约 1.2–1.8 万亿，剩下约 4.2 万亿必须来自新类别，而不是把旧流程多挤一点效率。关键证据：超大规模厂商 2026 年 capex 或达约 7800 亿美元；Bain 列出搜索广告替代（约 1000–2000 亿）、自动驾驶/工业自主（约 4000 亿）、物理 AI/数字孪生与机器人（约 9000 亿）及药物/能源等新用途；硬件/半导体股价 2020–2026 年 CAGR 约 24%，软件约 6%，且 HBM 挤占使 DDR/NAND 投资不足、加重手机 PC 涨价。增量：把“ROI 焦虑”从芯片短缺改写成全球 GDP 需额外约 1 个点来支付基建的宏观账。边界：25% capex/收入比率与四年后新品类规模高度假设；未充分处理泡沫破裂或开源/专用模型压价路径；报告主文 9 月 29 日已发，今日作框架深读而非突发硬新闻。

Anthropic Engineering：Scion 不是“又一个 git 替代”，是 Agent 永远在线假设下的源控重写

核心论点：当合并量与 checkout 量进入 Agent 量级，去中心化完整克隆成为负债；源控应假设客户端永远在线、计算上移服务器、派生数据可水平扩展。关键机制：changeset 相对第一父提交只存变更文件；blame/历史等为递归派生数据；checkout 协议按树/blob 按需拉取、缓存命中率自称 >99%；工程师角色变成“对 Claude 说不”、审意图而非逐行。增量：把 CI/合并队列失效（测试跑时已有成百上千变更合入）写成可观察的组织现实，并给出 Piper/Sapling 之后的 Agent 时代样本。边界：Anthropic 内部 token 预算远超一般企业，方案不可直接搬用；无开源；对“代码质量与技术债爆炸”缺少外部审计数据。
预估阅读：约 30 分钟。
